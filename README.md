# Prompts Manager

Este projeto é uma aplicação web simples para gerenciar prompts, desenvolvido durante a Rocketseat NLW Pocket.

## Estrutura do Projeto
- `index.html`: Página principal da aplicação
- `script.js`: Lógica JavaScript para interatividade
- `style.css`: Estilos da interface
- `assets/`: Imagens e outros recursos estáticos

## Como usar
1. Clone este repositório:
   ```sh
   git clone https://github.com/seu-usuario/prompts_manager.git
   ```
2. Abra a pasta do projeto no seu editor ou navegador.
3. Basta abrir o arquivo `index.html` para visualizar a aplicação.

## Tecnologias Utilizadas
- HTML
- CSS
- JavaScript

## Créditos
Projeto desenvolvido durante o evento NLW Pocket da Rocketseat.
